# Penetration Testing Report – Week 2

## Footprinting, Reconnaissance & Network Scanning

This repository documents a cybersecurity practical exercise covering website
footprinting/reconnaissance and local network scanning.

### Target / Scope

- Web target used during reconnaissance: `networkwalks.com`
- Local network scanned in the practical: `192.168.1.0/24`

### Tools Used

- Kali Linux
- WHOIS
- nslookup
- WhatWeb
- curl
- wafw00f
- DNSRecon
- Zenmap / Nmap

### Activities

1. WHOIS information gathering
2. DNS resolution with nslookup
3. Web technology identification with WhatWeb
4. HTTP response/header inspection with curl
5. WAF identification with wafw00f
6. DNS enumeration with DNSRecon
7. Local network discovery with Zenmap
8. Network topology visualization
